# Anki Deck Support

A support website and issue tracker for Jerry Li's published Anki decks.

**Website:** https://jerryli27.github.io/anki-deck-support/

Use the website's email form to send a private report without a GitHub account, or [open an issue](https://github.com/jerryli27/anki-deck-support/issues/new?template=deck-support.yml) for a public discussion. Please include the deck name, the card question, and what needs correcting.

The static website is served by GitHub Pages from `main`, folder `/docs`. Email delivery is handled by [FormSubmit](https://formsubmit.co/); its recipient activation is required before messages are delivered. The form retains the service's default spam check and adds a honeypot.

No Anki collection, review history, or deck package is stored in this repository. This is an independent support site, not an official Anki service.
