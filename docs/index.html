Before you send

A few quick answers.

Where can I find the exact card?

In Anki’s Browse window, select the card and copy its question into your message. If it has an ID field, including that can help too.

What helps with an image, audio, or display problem?

Include your Anki app and version, your device, and the card’s question. Describe whether the problem affects one card or several. You can add screenshots to a public GitHub issue; don’t post private information.

Are reports here public?

The email form sends a private message. GitHub issues are public and can be read by anyone, so use the email form if you prefer a private conversation.

Will deck updates arrive automatically?

Shared-deck updates usually require downloading the updated deck from AnkiWeb and importing it again. Syncing your own Anki collection does not fetch a shared deck’s latest release.
