# Anki Deck Support

A support website and issue tracker for Jerry Li's published Anki decks.

**Website:** https://jerryli27.github.io/anki-deck-support/

Use the website's direct-email link to send a private report, or [open an issue](https://github.com/jerryli27/anki-deck-support/issues/new?template=deck-support.yml) for a public discussion. Please include the deck name, the card question, and what needs correcting. The automatic email form is temporarily disabled while delivery is being connected.

The static website is served by GitHub Pages from `main`, folder `/docs`. The initial form integration uses [FormSubmit](https://formsubmit.co/), but delivery has not been activated or verified. The website provides working direct-email and issue-tracker options in the meantime.

No Anki collection, review history, or deck package is stored in this repository. This is an independent support site, not an official Anki service.
